Schema mismatch - your Weaviate instance has the OLD schema, but the Streamlit app expects the NEW schema.                                                                                                                          
                                                                                                                                                                                                                                                           
  Current Schema (OLD)                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                           
  CodeArtifact  ← Generic artifact class (old design)                                                                                                                                                                                                      
  Project       ← Project metadata                                                                                                                                                                                                                         
  DtoArtifact   ← Added in Feature 004                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                           
  Expected Schema (NEW)                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  The app expects specialized artifact types from Features 001-007:                                                                                                                                                                                        
                                                                                                                                                                                                                                                           
  BackendDoc         ← Backend services/classes                                                                                                                                                                                                            
  DaoCall            ← Data access objects                                                                                                                                                                                                                 
  DbTable            ← Database tables (what you're looking for!)                                                                                                                                                                                          
  GwtModule          ← GWT modules                                                                                                                                                                                                                         
  JspForm            ← JSP forms                                                                                                                                                                                                                           
  IbatisStatement    ← iBATIS SQL statements                                                                                                                                                                                                               
  GwtEndpoint        ← GWT RPC endpoints                                                                                                                                                                                                                   
  GwtUiBinder        ← GWT UI templates                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  Why This Happened                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                           
  The codebase evolved to use typed artifact classes instead of the generic CodeArtifact class. Your Weaviate container has old data from before this change.
