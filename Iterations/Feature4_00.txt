  Feature Overview

  This feature addresses the file reading issue by implementing Maven dependency resolution and DTO analysis capabilities:

  Problem Solved:
  - Current system only analyzes files in immediate project directory
  - Missing code in dependent Maven modules (referenced in pom.xml)
  - No understanding of DTO patterns for data transfer analysis

  Solution Implemented (in spec):

  1. Maven Dependency Resolution (P1 - Priority 1)
    - Parses pom.xml dependencies (groupId, artifactId)
    - Resolves to: JAVA_SOURCE_DIR/artifactId/
    - Supports --project parameter: JAVA_SOURCE_DIR/project/
    - Handles circular dependencies, missing artifacts gracefully
    - Configurable depth with --dependency-depth
  2. DTO Pattern Recognition (P2 - Priority 2)
    - Identifies DTOs by naming (*DTO, *Request, *Response, etc.)
    - Extracts field definitions and validation annotations
    - Detects serialization markers (Serializable, IsSerializable)
    - Captures nested DTO relationships
    - Differentiates DTOs from JPA entities
  3. Project-Scoped Analysis (P3 - Priority 3)
    - --project parameter for monorepo support
    - Targeted analysis of specific modules
    - Path resolution relative to project directory
