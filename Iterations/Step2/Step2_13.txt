  ## Key Technical Components

  ### 1. Analyzer Services

  **DatabaseAnalyzer** (`src/codeindex/services/db_analyzer.py`)
  - Discovers JPA entities, iBATIS XML, Liquibase migrations
  - Uses Ollama LLM to understand schema semantics
  - Extracts business rules from constraints and annotations
  - Outputs structured JSON artifacts

  **ServiceAnalyzer** (`src/codeindex/services/service_analyzer.py`)
  - Discovers Spring services, controllers, repositories
  - Extracts API endpoints with full specifications
  - Analyzes service dependencies and injection
  - Identifies transactional patterns

  **FrontendAnalyzer** (`src/codeindex/services/frontend_analyzer.py`)
  - Discovers JSP forms, GWT modules, JavaScript
  - Extracts form fields with validation patterns
  - Maps form submissions to backend endpoints
  - Analyzes UI component hierarchies

  ### 2. Supporting Services

  **VisitLog** (`src/codeindex/services/visit_log.py`)
  - Incremental processing with content hash tracking
  - JSONL format for efficient append-only writes
  - Enables `--force-refresh` to skip unchanged files

  **MarkdownBuilder** (`src/codeindex/services/markdown_builder.py`)
  - Generates professional PRD markdown documents
  - Table-driven entity catalogs
  - Cross-references and internal links
  - Mermaid diagram support (optional)

  **PRDGenerator** (`src/codeindex/services/prd_generator.py`)
  - Master PRD orchestrator
  - Loads artifacts from all layers
  - Technology and domain detection
  - Cross-layer mapping generation

  ### 3. Data Models

  **Enhanced PRD Models** (`src/codeindex/models/prd.py`)
  - `DatabaseEntity`: Table/entity definitions
  - `BusinessRule`: Rule specifications with severity
  - `ServiceDefinition`: Service class documentation
  - `APIEndpoint`: REST/SOAP endpoint specs
  - `FormDefinition`: UI form specifications
  - `UIComponent`: Frontend component docs

  ### 4. CLI Command

  **PRD Command** (`src/codeindex/cli/prd.py`)
  - Layer selection: `database`, `services`, `frontend`, `full`
  - Project filtering support
  - Parallel LLM processing (default: 10 workers)
  - Force refresh option
  - Comprehensive error handling and progress reporting

  ## Usage Examples

  ```bash
  # Generate full PRD for a project (all layers + master PRD)
  codeindex prd full --project myapp --output-dir ./docs/prd

  # Analyze only database layer
  codeindex prd database --project myapp

  # Analyze with custom LLM settings
  codeindex prd services --llm-timeout 180 --parallel 20

  # Force refresh all files (ignore visit log)
  codeindex prd --force-refresh --project myapp

  # Generate specific domain only
  codeindex prd --domain-filter authentication --project myapp
