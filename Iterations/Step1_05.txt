  Key Design Decisions

  1. Architecture: Single CLI application with streaming pipeline
  2. Technology Stack: Python 3.8+, Click, httpx, lxml, weaviate-client, pytest
  3. Concurrency: Threading with Semaphore (10 concurrent AI requests default)
  4. Storage: Weaviate for persistence, JSONL for intermediate data
  5. Performance: Streaming generators, batched writes, deterministic UUIDs
  6. Safety: Per-project file locking, idempotent indexing, retry logic
