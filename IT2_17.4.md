## Fix applied

### Problem
The extraction was picking "mnt" from the path instead of project directories because it wasn't using `JAVA_SOURCE_DIR` as the base.

### Solution
Updated `extract_project_name_from_path()` in `src/config/project_utils.py` to:
1. Use `JAVA_SOURCE_DIR` as the base directory (highest priority)
2. Extract the first subdirectory after `JAVA_SOURCE_DIR` as the project name
3. Ignore system paths like `mnt`, `cucocalcai`, `cuco-master`

### Example
- Path: `/mnt/cucocalcai/cuco-master/cuco-master@d34bb6b6d1c/cuco-ui-cct-a1voip/src/...`
- JAVA_SOURCE_DIR: `/mnt/cucocalcai/cuco-master/cuco-master@d34bb6b6d1c`
- Extracted project: `cuco-ui-cct-a1voip`
