 Index multiple directories → Generate PRDs for each:                                                                                                                                                                                                     
                                                                                                                                                                                                                                                           
  # 1. Index each project separately                                                                                                                                                                                                                       
  ./run.sh project-a /path/to/project-a                                                                                                                                                                                                                    
  ./run.sh project-b /path/to/project-b                                                                                                                                                                                                                    
  ./run.sh project-c /path/to/project-c                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  # 2. Verify indexing                                                                                                                                                                                                                                     
  codeindex status                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                           
  # 3. Generate PRDs with project filtering                                                                                                                                                                                                                
  codeindex prd full \                                                                                                                                                                                                                                     
    --project "com.example:project-a:1.0.0" \                                                                                                                                                                                                              
    --source-dir /path/to/project-a \                                                                                                                                                                                                                      
    --output-dir ./output/project-a-prd                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  codeindex prd full \                                                                                                                                                                                                                                     
    --project "com.example:project-b:2.0.0" \                                                                                                                                                                                                              
    --source-dir /path/to/project-b \                                                                                                                                                                                                                      
    --output-dir ./output/project-b-prd                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  🏗️ How It Works                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                           
  1. Each project gets a unique ID from Maven coordinates:                                                                                                                                                                                                 
    - com.example:myapp:1.0.0 (from pom.xml)                                                                                                                                                                                                               
    - Or path-based hash for non-Maven projects                                                                                                                                                                                                            
  2. All projects coexist in single Weaviate:                                                                                                                                                                                                              
    - Each artifact tagged with project ID                                                                                                                                                                                                                 
    - Projects isolated via filtering                                                                                                                                                                                                                      
    - No conflicts between projects                                                                                                                                                                                                                        
  3. PRD generation filters by project:                                                                                                                                                                                                                    
    - --project flag isolates artifacts                                                                                                                                                                                                                    
    - Each project gets separate output directory                                                                                                                                                                                                          
    - Can generate PRDs in parallel
