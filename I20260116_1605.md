  Root Cause: DbTable Artifacts Not Indexed                                                                                                                                                                                                                
                                                                                                                                                                                                                                                           
  DbTable artifacts are created from SQL DDL files during the extraction phase:                                                                                                                                                                            
                                                                                                                                                                                                                                                           
  1. What creates DbTable artifacts:                                                                                                                                                                                                                       
    - CREATE TABLE statements in .sql files                                                                                                                                                                                                                
    - iBATIS XML <sql> tags with DDL                                                                                                                                                                                                                       
    - Database schema files                                                                                                                                                                                                                                
  2. Discovery → Extraction → Indexing pipeline must run first:                                                                                                                                                                                            
  # Check if you've indexed your codebase                                                                                                                                                                                                                  
  cd /home/tkamsker/development/Iteration20/gha1javarag                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
  # Run discovery                                                                                                                                                                                                                                          
  codeindex discover --source-dir /path/to/your/java/source --output ./output/discovery.jsonl                                                                                                                                                              
                                                                                                                                                                                                                                                           
  # Run extraction

  # Run indexing                                                                                                                                                                                                                                           
  codeindex index --inventory ./output/discovery.jsonl --extraction ./output/extraction.jsonl
