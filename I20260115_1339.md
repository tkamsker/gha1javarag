  The Fix:                                                                                                                                                                                                                                   
  Added parameter mapping layer in get_agent_config():                                                                                                                                                                                       
  - Maps "verbosity" → "verbose":                                                                                                                                                                                                            
    - "concise" → verbose=False                                                                                                                                                                                                              
    - "standard" / "detailed" → verbose=True                                                                                                                                                                                                 
  - Filters unknown parameters to prevent TypeErrors                                                                                                                                                                                         
  - Keeps UI settings decoupled from agent internals
